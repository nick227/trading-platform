# RP-05 — Research Partner workspace

Authenticated /research-partners provides create, mandate preview/approval, research questions, report inspection and history. It has no trading controls and displays only live API results.

In the current phased rollout, mandate previews are labeled manual and research execution can return unavailable until the independent budgeted provider flag is explicitly enabled. Queued questions remain visible as saved investigations.

No external evidence provider or investment performance data is synthesized by the UI.
